# 浮屿 ISOLA

基于 HTML、Three.js 和 Vite 的交互海岛。可以漫游海岸、码头、泻湖、山洞、山顶亭与灯塔，观看昼夜、四季、天气和天象，聆听海浪与器乐。

## 当前版本：v1.4.0

本版本的重要更新：

- **六部实时影片**：新增影片列表与播放器，提供《四时一日》《夜的回声》《观云》《渔舟唱晚》《听雪》和《彩虹》，支持暂停、拖动、倍速、音量、截图与全屏。
- **镜头与场景调度**：统一编排天气、云量、月相、天象、灯光、生物与声音；音乐保持原速，退出恢复原漫游设置。
- **风雨与彩虹**：60秒《彩虹》以《平沙落雁》配乐，展示晴天、暴雨、台风、巨浪与雨后彩虹；逆风飞鸟放大，结尾字幕为“风雨之后，总会有彩虹。”
- **花海与生物**：丰富花瓣、花粉与松鼠毛皮质感，加入花丛昆虫、林间动物、夏夜萤火虫与飞蛾，完善停花和自然退场。
- **渲染与播放优化**：改进场景剔除、森林分块和离屏更新，暂停观影按需重绘，完善云图加载、相机构图、音乐恢复和资源释放。

各版本人工聚合的重要更新保存在 [release-notes.json](src/config/release-notes.json)，按最新版本在前排列，并由设置面板直接读取。

## 启动

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

打开终端显示的本地地址。项目使用 ES 模块，需要通过服务器访问；运行时不访问第三方素材服务器。素材生成工具仅在重新制作素材时使用。

## 修改配置

| 文件 | 维护内容 |
| --- | --- |
| [defaults.json](src/config/defaults.json) | 初始时间、速度、季节、自动轮换、诗与漫游开关、天象默认模式和随机等待、资源超时与重试 |
| [weather.json](src/config/weather.json) | 天气预设、雨与台风循环、云量档位及图标、季节候选、温度及自动天气轮换 |
| [camera.json](src/config/camera.json) | 初始视角、各观景位置、视野与控制距离 |
| [rendering.json](src/config/rendering.json) | 默认画质、像素比例、帧率、曝光和星点数量 |
| [fish-wave.json](src/config/fish-wave.json) | 鱼群跃浪的时段、等待、阶段、数量与海域筛选 |
| [butterflies.json](src/config/butterflies.json) | 花丛蝴蝶的画质数量、配色、活动天气、停留与恢复时长及距离更新策略 |
| [meadow-insects.json](src/config/meadow-insects.json) | 蜜蜂采蜜与换花、蜻蜓停悬、分档数量、活动天气与距离更新策略 |
| [woodland-wildlife.json](src/config/woodland-wildlife.json) | 林鸟飞落停栖、松鼠攀爬与偶尔穿路、分档数量和天气退场 |
| [night-wildlife.json](src/config/night-wildlife.json) | 夏夜萤火虫群闪、飞蛾掠灯、温度天气条件及分档数量 |

配置通过静态导入随应用打包，不增加额外的配置下载请求。修改 JSON 后开发服务器会更新页面；部署前需要重新构建。运行时随机种子仍现场生成，每个新场景使用独立状态；几何和着色器公式保留在对应实现中。

默认进入夏日晴天，时间 14:30，速度 0.5×，桌面与手机均使用精细画质，自动轮换天气、季节和月相；诗和声音默认关闭，背景乐音量 80%、环境音 30%。声音始终遵守浏览器的用户手势限制。

白天可近看花丛蝴蝶和蜜蜂停花、蜻蜓悬停，以及山径旁林鸟落枝与亭栏、松鼠攀树和偶尔穿路。每次进入会重新选择一批真实树木、枝条与安全穿路路线，林鸟偶尔选择同伴附近的空落点结伴停留。温暖平静的夏夜，萤火虫每晚换一批林缘小群，数量疏密与闪烁节奏各异；跨午夜或同夜雨后不换区域，换夜时先渐退再出现。少量飞蛾从随机方向短暂掠过亭灯。恶劣天气时这些生物逐渐退场，残雪融尽后恢复；亭灯关闭后飞蛾离开。

场景使用视锥剔除减少镜头外绘制；森林近景按空间分块，全景保留原实例批次，兼顾三角形数量和绘制次数。生物离开镜头时跳过姿态上传，行为时钟继续，转回时显示当前状态。阴影按光源视野独立判断，海天和带特殊顶点运动的物体保留各自的边界处理。

### 宣传片播放列表

点击设置标题栏版本号左侧的电影图标，在原设置弹窗内打开影片列表；片单在一个框内逐行显示并可内部滚动。电影图标前固定预留一个返回按钮，按访问顺序回到上一页，关闭再打开保留上次页面和滚动位置；每部影片前有播放图标，点击该行即开始播放。目前内置《浮屿 · 四时一日》（3分钟）、《浮屿 · 夜的回声》（3分钟）、《浮屿 · 观云》（60秒）、《浮屿 · 渔舟唱晚》（60秒）、《浮屿 · 听雪》（60秒）和《浮屿 · 彩虹》（60秒），使用现有场景、音乐与自然声。底部为通栏进度条，左侧播放/暂停与当前/总时间，右侧倍速、音量（竖向滑杆）、截图、全屏与退出；选片默认进入全屏（手机随设备横竖方向），点击画面暂停/继续；底栏平时隐藏，鼠标移到底部或触屏轻触底部唤出，触屏操作结束后约2.5秒收起；拖回开头即可重看，Esc先退出原生全屏再退出影片；支持拖动进度预览和跳转；倍速默认1.0×，点击打开选项菜单，可直接选择0.5、1.0、1.5、2、3、4倍速，镜头和字幕按倍率播放，音乐保持原速。切后台自动暂停，返回后点击继续。暂停期间仅在拖动、转屏、截图或贴图就绪时重绘；横竖屏切换立即适配当前构图。隐藏底栏跳过逐帧进度更新，唤出立即同步。

《听雪》以《孟姜女哭长城》配乐，7个镜头依次展示初雪、亭檐积雪、暴风雪、礁岸汹涌海面与雪夜亭灯，末三秒留白。

第二版影片支持通用场景调度：参数轨道控制天气、月相、灯光、生物数量和分段运动速度，过程片段控制流星、彗星、极光与日月食。夜景影片压缩为13个镜头，月相八秒连续变化，星座同时展示连线与名称，血月作为结尾；音乐保持原速，退出恢复漫游设置。

脚本直接维护在 `src/assets/data/films/*.json`，新增合规文件后自动加入网页播放列表，部署前重新构建。没有网页导入导出，也不生成视频文件；制作新片需编写独立镜头脚本，方法见 [宣传片脚本说明](docs/film-scripts.md)。

退出恢复原视角、时间、天气、自动轮换和音乐模式、曲目与进度。电影只临时安排展示环境，动物继续按原规则自然活动；模型动画时钟保持连续，重播不会倒退生物状态。花瓣共享约245KB的Imagegen柔和组织纹理，花头采用三圈独立错落的圆瓣，单瓣从浓色根部渐变到柔和透亮的边缘，保留赤橙黄绿青蓝紫等鲜艳花色，并按花簇错落分布；洞前花蕊为错落的短密花粉簇，并共享约380KB的Imagegen花粉颗粒纹理，独立以白、粉、红、黄为主，叶片复用阔叶纹理。松鼠使用约116KB的Imagegen毛皮纹理，加强毛根与毛尖明暗及细毛凹凸，增加头部观察、步态与尾部动作，并沿地面跑出视野或绕树遮挡后离开。纹理首帧后按需加载；首屏不下载音频。花海按六个花簇分级，近景保留完整细节，远景简化曲面和茎叶；株数、花色和昆虫落点保持稳定。

### 添加或替换音乐

1. 将 MP3 放入 `src/assets/music/`。
2. 在 `music.json` 的 `tracks` 中加入唯一的 `id`、显示用 `title` 和 `file` 文件名。
3. 普通曲目会自动进入随景播放列表；日落曲目由 `playlists.sunset.trackId` 指定。
4. 执行资源检查、测试和构建。无需再修改播放器中的导入列表。

曲谱、合成方式与素材说明见 [音乐说明](src/assets/music/README.md) 和 [脚本说明](scripts/README.md)。普通音乐与日落音乐复用流式播放器，最多使用两个媒体节点；下一首未准备好时保留当前曲目，不叠加底乐。

## 操作

- 拖动旋转，滚轮缩放；触屏单指旋转、双指缩放。底部切换全岛、海岸、码头、浅海、泻湖、山洞、两座观景亭、灯塔与赏月视角。
- 设置中切换季节、天气、时间、速度、月相和画质；雨按钮循环普通雨、台风、关闭，云按钮循环默认（仅v1）、全部云形·少、中、多。日食、月食位于月相之后。相关天象按钮可切换随机出现、立即出现和关闭。
- 星座支持隐藏、连线与名称、仅连线；极光在冬夜可见。人工灯光可自动变化、关闭灯塔或关闭全部。
- 首次点击声音或播放按钮启用音频；支持暂停、下一首及播放方式切换。诗句在符合满月与可见性条件时显示。
- 相机保存无界面风景 PNG；全屏与禅模式用于沉浸观看。禅模式中点击省略号恢复界面。
- 设置标题栏的电影图标打开可滚动的片单，返回按钮回到上一页；选片播放后可暂停、调速、拖动和退出，Esc 退出。
- 手机默认收起设置。性能不足时选择均衡或流畅画质。

## 验证与构建

```sh
npm run check:resources
npm test
npm run build
npm run preview
```

自动测试采用受限并发，避免大量模型同时构建。生产结果写入 `tmp/build/`；不要把临时截图、日志或构建产物提交到源码目录。

重新制作素材时可能需要 NumPy、Pillow 或 ffmpeg。音乐时值回归使用与合成脚本相同的 Python 环境：

```sh
PYTHONPYCACHEPREFIX=tmp/python-cache python3 tests/test_scenic_score_timing.py
```

启动开发服务器后，可通过以下页面进行真实 GPU 验收：

- `/tests/materials-browser.html`：材质、海床和石阶。
- `/tests/lunar-eclipse-browser.html`：偏食、红色日冕、血月和复圆。
- `/tests/solar-eclipse-browser.html`：日食和日冕。
- `/tests/performance-audit-browser.html`：场景性能采样。
- `/tests/fish-wave-browser.html`：鱼群跃浪及随机海域验收。
- `/tests/bloom-gpu.html`：辉光异常值回归。

资源体积、长期缓存优化与测量边界详见 [性能与资源检查](docs/performance-and-resources.md)。

## 开发与发布

本项目以 `main` 为基线。开始新任务时先同步 `origin/main`，再创建不跟踪主分支的 `feat/` 分支；当前未提交工作需先保护。未经明确授权不提交或推送，完整规则见 [AGENTS.md](AGENTS.md)。

GitHub Pages 工作流 `.github/workflows/deploy.yml` 在 `main` 执行安装、测试与构建，成功后发布 `tmp/build/`。手动运行其他分支仅验证、不发布。部署使用相对路径，支持多层网站子目录；不要传入旧的固定 `--base`。

手动部署时，复制 `tmp/build/` **里面的全部内容**，包括 `index.html` 与完整 `assets/`，到目标静态目录。不要上传项目根目录的源码 HTML，也不要只替换构建后的 HTML。

## 素材与实现

海岛、植被、动物、风浪和环境音由程序生成；多种表面纹理由 Imagegen 生成，提示词保存在 `prompts/textures/`。月面使用 NASA CGI Moon Kit 的 LRO 数据，书法字体使用 Ma Shan Zheng 子集。来源与署名见 [public/licenses](public/licenses/)；字体及音乐制作细节随对应目录保留。

无损纹理编码工具：`python3 scripts/assets/optimize-texture.py 原图.png 输出.webp`。工具保留尺寸和透明度，并校验全部 RGBA 字节；没有为缩减体积降低现有 MP3 码率。

这是用于观赏与放松的实时场景，天象的时间、尺寸和染色采用艺术化呈现，不是精密天文模拟。建议使用支持 WebGL 2、开启硬件加速的浏览器。
