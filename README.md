# 浮屿 ISOLA

HTML + Three.js 交互海岛：动态海洋、自然山体、沙滩、椰子树、森林、花朵、礁石、码头和海鸟，搭配昼夜与四季轮换、六种天气以及环境声场。

## 启动

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install --registry=https://registry.npmjs.org
npm run dev
```

浏览器打开终端显示的本地地址。项目使用 ES 模块，需要通过本地服务器访问。

## 操作

- 页面打开时显示海风与涟漪加载动画，19句海岛搭建文案随机轮播，每句带省略号；实际场景准备好后自动淡出。
- 鼠标拖动旋转，滚轮缩放；触屏单指旋转、双指缩放。
- “环岛漫游”控制镜头自动环绕；下方可选全岛、海岸、码头、浅海、泻湖、山洞、南峰亭、东峰亭、灯塔和赏月视角。“赏月”会在白天切换至夜晚，保留当前天气和月相；赏月环绕限制俯仰范围以保留天空，月盘保持在相同背景位置。
- 环境面板可切换春夏秋冬、晴天、阴天、雨天、雾气、雷暴和飘雪。
- 全岛道路共7条、约721米：环岛沙土步道连接南侧码头，1.1米宽山径沿坡回折、通过鞍部连通三座山头。上山、山脊和洞口外支路采用连续水平天然石阶与短转弯平台，最陡纵坡约31°；落脚点紧邻真实峰顶。另有约24米的石阶支路，从山脚经环岛路下降到南侧偏左的干沙海滩。灰褐土砾、坡边挡土石与局部台地融入山体，沿路有野花、草丛和散落碎石。
- 西侧最高峰顶旁增加白墙石基灯塔，门口连接山顶石阶。旧墙、窄窗、木门、圆形栏杆和铜红色塔顶融入山体；傍晚灯室渐渐亮起暖金色灯光，两束柔和灯束缓慢旋转，天亮后熄灭。暂停昼夜时扫光仍持续，流畅画质也保留灯塔和夜灯。
- 上山、三峰山脊与洞口支路的外侧设有稀疏交错的木铜矮杆路灯，暖金灯芯在傍晚渐亮，并有局部灯光照亮石阶；天亮后熄灭。灯脚贴住实际坡面，流畅画质也保留灯体与发光。
- 南峰和东峰顶的观景木亭由木柱支撑架空木板地面，采用朱红木柱梁、中式攒尖瓦顶、上翘飞檐、檐下花格与三面长凳。左右和背面由木栏杆围合，只留连接山径石阶的一面作为入口；夜晚暖灯渐亮，冬季屋顶覆雪。底部“南峰亭”和“东峰亭”可直接观看并拉近；手机视角按钮采用两行排列。
- 围栏采用与檐下花格呼应的朱红框式格纹。南峰亭前的末段石阶持续缓升，踏面加深，门前留有整宽落脚平台；东峰亭入口与接路台阶同轴，便于从山路平稳转入木台。
- 南亭直接接原路平台；东亭门前采用单块整宽落脚接阶，避免两级浅阶的重复层次，沿用山径石材与纹理。东亭高平台外侧用顺坡展开的不规则粗石支撑衔接山体；主梯按平台实际边缘接入，清除被盖住的重叠踏面，转弯处保持平顺。
- 前方偏右的浅水泻湖由原沙滩和不规则半环沙洲围成，通海口连着外海。真实浅海床与原海水一起形成蓝绿水色、岸边浪花和连续倒影；沙洲遮蔽使池内波浪和白沫更柔和。池内常驻三小群鱼和海龟，湿岸有螃蟹，浅湖底有龙虾；鱼尾、龟鳍、步足、钳和虾须持续运动，底栖动物交替走动与停留。选择“泻湖”后滚轮拉近观察，昼夜与天气切换不会移除居民，流畅画质也保留四类动物。
- 山侧洞口真实切开地形，岩缘采用多层破碎断面，独立颜色、凹凸和粗糙度石纹增加矿物颗粒与裂隙。洞顶和两侧覆有茂密贴岩蕨草、长短不均的藤蔓，叶尖随风轻摆，入口与台阶保留通行空间；内部是起伏泥土、碎石和逐渐变暗的岩壁。洞口无灯，洞内第一个转角后藏有一盏局部暖光，光照范围不到洞口，后段仍看不到尽头。洞前支路经上山路和海滩石阶连续通到干沙地。底部“山洞”视角可以拉近观察。
- 山体近景可见扭曲岩层、裂隙、细颗粒和凹凸光影，坡面小型露岩增加真实轮廓；雨天岩面逐渐变湿。普通树林采用分层细枝、独立弯曲叶片和不规则叶簇，枝叶间透光，树皮带纵向裂纹，季节调色、风动与积雪保留。椰子树沿用原形态。
- 海风在天气基础上平滑随机变化，面板显示当前风速。海面涌浪、风向和浪花随之变化，树干、分叉和树冠整体弯曲，椰干、椰叶与椰果协调摇动，草丛和路边草花随阵风摆动；根部固定，阴影同步。暂停昼夜后风、植被和海浪仍继续运动。
- 海水保留近岸蓝绿、远海深蓝的水深渐变；阴雨降低饱和度，偏灰青与灰蓝，雾天更灰淡。水色随云量、雷暴与雾强度平滑变化，月夜保留深蓝与金色倒影。
- 月夜远海与低空共用同一夜色，海雾随距离逐渐遮淡远处波纹，并在不同方位缓缓改变浓淡；海天交界更朦胧，近岸浪花、金色月光和小岛仍保持清晰。
- 双击岛上的位置可平滑拉近并围绕点击点观察，反复双击可继续靠近；手机支持双击，拖动与双指缩放不会误触发。拖动环绕、滚轮缩放仍可自由使用，点击“全岛”返回远景。
- 昼夜滑块精确调节时间，支持自动轮换、暂停和多档时间流速；空格键也可暂停轮换。
- 晴朗白天可见暖白太阳、柔和日晕和细光芒，小岛的阳光阴影与海面碎光朝向同一轮太阳。日出、日落时太阳穿越地平线，晨光与夕阳染暖天空、云层和海面；云雨雪雾会遮蔽日盘和直接反光，夜间隐藏太阳。昼夜滑块可直接观看清晨 6 点、傍晚 17 点到 18 点的变化。
- 晴朗傍晚的日盘随下降由金橙渐变为朱红，火烧云保留金红亮边、橘粉云体和蓝紫暗部；太阳沉落后仍有短暂的玫紫余晖。海面沿夕阳方向映出暖色云霞，近岸保留蓝绿水体。可将时间暂停在 17:48 或 18:00 观看。
- 云量随场景种子缓慢随机变化，晴天会经历少云、大片白云和接近万里无云的天空；阴雨、雷暴和飘雪保留相应的厚云。各阶段持续数十秒，以淡入淡出过渡，海面的云影随同一云量变化；暂停昼夜轮换时，云量与漂移仍继续。
- 月亮从海平线缓缓升起，午夜到达高处，黎明渐渐下降；水平构图跟随镜头，环绕旋转仍保留背景中的月亮。月相随模拟日期按约 29.53 天循环变化。昼夜区内可选择新月、娥眉月、上弦月、盈凸月、满月、亏凸月、下弦月和残月；手动选择会关闭月相自动轮换，可重新开启。暂停时间也会暂停月相。
- 满月保留较大的金色月面构图；月牙、弦月与凸月采用与日盘接近的自然比例。自动轮换到接近满月时平滑放大，离开满月后平滑缩回。
- 非满月只显示受光的月面，暗部完全透出天空，不保留灰色圆盘；受光侧靠近明暗交界的细边略微提亮，并保留月面纹理与柔和过渡。
- 落日完全沉入地平线后，月亮随暮色加深渐渐出现；黎明时反向淡出，避免夕阳与夜景大月盘同时出现的比例冲突。
- 清晰明月下增强环境补光和海面漫反射，树林、山体、沙滩与远海可辨；云雾遮月和新月时照明减弱，保留夜间层次。
- 仅在清晰明月下，张若虚《春江花月夜》会以立体金色毛笔字逐联浮现，诗句无标点，引言署名为“唐 张若虚”。文字安排在月亮左侧的天空，竖排从上到下、列从右到左；天空空间较窄时采用两行横排，俯视没有足够天空时隐藏。停留后渐隐、随风飞散或散向海面。完整 36 句循环，右上角“诗”按钮控制开关；可见度跟随实际月盘，多云时明月清晰也会显示，白天、新月及月盘被浓云雾遮蔽时隐藏。点击“赏月”会重新开始诗句。
- 云层具有明亮顶部、蓝灰底部和细碎边缘，随海风缓慢漂移；不同高度、薄云和个体有速度差，风向转变平滑过渡。椰叶、树冠与草叶随阵风轻摆，叶根保持固定，树冠阴影同步。普通倍率下，云与植被仍按真实时间运动。新增16×会同时加快全部场景动画、昼夜和四季，并随机固定一首器乐曲以原速循环；事件声效每三秒最多一次，鸟鸣减少。选择其他倍率即可恢复原有动画与随景音乐逻辑，累计动画时间保持连续。雨天或雷暴转晴后，白天会短暂出现柔和彩虹，渐显后逐渐消散。
- 海鸟分散在岛上与海岸，交替拍翼、盘旋和滑翔；浅海镜头可观察三类鱼群；每次进入场景，鱼群在安全的近岸水域随机分布，并沿连续路径游动。晴朗时在全岛或具有开阔远海的海岸视角等待约十秒，可看到鲸鱼浮背喷水，海豚随后在独立时段跃出。鲸鱼约每34至41秒活动一次；海豚按12至19秒的随机候选间隔活动，遇到鲸鱼活动会顺延。海豚每群随机1至4只，画质较低时限制人数；每轮重新选择安全的远海位置，整次活动保持连续路径。鲸鱼含尾长约25米，主要身体留在水下，宽背与持续喷雾浮出。明亮月夜也可能活动，恶劣天气和暗夜减少活动；被岛遮挡或镜头转离时取消当前活动及对应声效，避免从同一轮重新冒出或补播旧声音。
- 每座亭子的四个檐角各悬挂一只小铜风铃，铃身、撞舌和风帆随海风错开轻摆；摆动撞击时响起有余音的轻柔铃声。拉近亭子能听得更清楚，远处减弱；暂停昼夜后风铃仍随风运动。
- 远海间歇出现单桅小帆艇、双桅传统帆船和低舱短桅渔船的剪影；船型、大小、数量、位置和慢速航行各不相同，白天与夜晚都可能看到。转移到新水域前渐渐淡出，雾雨中自然减弱。
- 点击扬声器或“点击开启”启动声音。背景音乐默认80%、环境音默认30%，分别可调；海浪由拍岸低频和退潮泡沫声组成，随涌浪、海风和天气起伏。风铃声由环境音滑块控制，雷声与闪电同步，鲸鱼呼气、海豚短鸣和落水声由相应动作触发，并按距离与左右方位调整声场。
- 设置分为“环境”和“声音与音乐”两个页签。音乐页将10首曲目按每页5首分页展示，通过上一页/下一页切换，无歌单内部滚动条；点击曲名立即播放；方式按钮依次切换随景播放、单曲循环、顺序播放、随机播放，速度按钮循环切换0.5×至2×并保留音高。暂停只停止背景音乐，环境音继续；手动选曲不受天气或16×场景倍速干扰，切回随景播放恢复原逻辑。
- 场景音乐为器乐主题节选合成版：晴日轮换《彩云追月》《山歌好比春江水》《我的祖国》，月夜轮换《春江花月夜》《彩云追月》《梁祝》《女儿情》《枉凝眉》，雨雾和秋景轮换《平沙落雁》《孟姜女哭长城》《梁祝》《枉凝眉》。普通场景变化会等当前曲目结束再选下一首；日落优先切换时旧曲先淡出、新曲再淡入，两首旋律不重叠。暂停和系统中断后恢复原曲进度，按需流式加载本地MP3，曲目速度不随模拟倍速改变。
- 连续点击“南峰亭”三次播放用户提供的《功德宝山咒》，连续点击“东峰亭”三次播放《心经》。两亭独立计数，选其他视角清空计数；第三次会开启声音并解除音乐暂停，离开亭子后恢复原曲。两首也属于隐藏诗句的专属音乐，不加入普通歌单。
- 连续点击“山洞”按钮第3次播放《桔梗花》、第5次播放《波如来》、第10次播放《梦中的额吉》、第12次播放《大悲咒》，切换视角或远离后清空，靠近山洞不自动播放专属歌曲。点击计数与凉亭独立，离开后清空，专属音乐播放时隐藏并暂停诗句。《大悲咒》开始播放时，灯塔（含光束）、山路、码头和凉亭立即全部熄灭；暂停、关闭声音或切回其他曲目时按当前昼夜恢复，太阳、月光与自然闪电照常运行。
- 洞口与台阶两侧新增多色野花，贴合地形、预留通道、随风摆动，两批实例绘制，冬季与积雪时休眠。
- 连续点击山洞第3次播放用户提供的《桔梗花》，离开后淡回原背景音乐。灯塔、码头、山洞专属音乐都隐藏动态诗句并暂停诗句进度，恢复背景音乐后继续原联，保持用户原有诗句开关。
- 连续点击码头第3次播放用户提供的《送别》，同次停留第6次及之后不重复触发，白天和夜晚都适用，远离码头后恢复原曲进度，与灯塔共用同一播放器，遵循暂停、音量和手动播放模式。
- “鸟瞰”按钮改为“灯塔”近景。连续点击灯塔第3、5、10、12次依次播放《月儿明风儿静》《鲁冰花》《花恋》《驼糕之歌》，不再靠近随机播放；其他点击只调整镜头。切换视角或远离清空计数，专属歌曲唱完恢复原普通音乐。
- 日落播放按天气预报旋律制作的《渔舟唱晚》电子琴合成版，约73秒，带柔和伴奏和余音；傍晚自动淡入，入夜后淡回场景音乐，清晨不触发。全部声部在本地合成并随网站打包，无需外部播放链接；[音源说明](src/assets/audio/README.md) 记录生成与替换方法。
- 右上角相机保存无界面风景 PNG；全屏按钮开启沉浸式观看。
- 右上角“诗”“禅”按钮并排放置，使用同一书法字体与字号；“禅”按钮隐藏全部界面，只保留“…”恢复按钮和原有动态诗句，再次点击恢复界面与原有面板状态。海岛、声音和自然轮换继续运行。声音未开启时扬声器按钮以红色闪烁提醒，开启后停止。
- 每次海岛加载完成后，画面中央盖下一枚巨大的“张在元”朱文篆刻印章，稍作停留，再缓缓缩小飞至左上角，全程约6秒；替代原圆形图标并一直方正显示。禅模式隐藏印章，退出后恢复显示，已结束的盖章动画不会重播。减少动态效果偏好下仅淡入。
- 手机默认收起面板，可通过右上角设置按钮打开；性能不足时选择“均衡”或“流畅”。

## 验证与构建

```sh
npm test
npm run build
npm run preview
```

辉光异常值的 GPU 回归：启动开发服务后打开 `/tests/bloom-gpu.html`。测试向 HDR 缓冲加入 NaN/Infinity，检查异常不进入辉光模糊链，并逐像素比较正常高光与原效果一致。结果显示 `pass: true`；需要支持 WebGL 2 的真实浏览器。

启动时地形、山路与植被分段构建，模型准备与资源下载交错进行；加载动画持续轮播，并显示当前准备阶段。首帧前预热着色器，不降低现有模型数量或画质。

构建输出位于 `dist/`，可部署到静态网站服务器。地形、云、粒子、音乐与音效在本地生成；月面贴图和书法字体随网站打包，运行时无需访问第三方素材服务器。

## GitHub Pages 部署

构建使用相对资源路径，同一份构建支持部署到 `/sometest/island/`、`/sometest/demo/island/` 或更深的子目录。

1. 执行 `npm run build`。
2. 将 `dist/` **里面的内容**（`index.html` 和完整的 `assets/` 文件夹）复制到仓库的 `demo/island/`，覆盖旧版本。
3. 按仓库现有的 GitHub Pages 发布方式更新网站，发布完成后刷新页面。

不要上传项目根目录的源码 `index.html`，也不要只替换构建后的 HTML 而遗漏对应的资源文件。保留默认的相对路径配置，不要在构建命令中传入旧目录的 `--base`。例如部署到 `/sometest/island/` 后，脚本和样式表应从 `/sometest/island/assets/` 加载。

## 实现

- 程序化海床和连续高度场，细分山体、植被实例化及季节材质。
- 多方向 Gerstner 波、随机波群和阵风、海深颜色、菲涅耳天空反射、逐像素细波、太阳与月亮高光、离岸碎浪、近岸破浪与回流泡沫，以及浅海焦散。未被网格解析的短波能量交给非周期细纹，逐层按像素尺度过滤，避免重复格纹；反射朝向海面时平滑回到水体色，减少不合理的白色反光带。实现参考 [GPU Gems 的水面模型](https://developer.nvidia.com/gpugems/gpugems/part-i-natural-effects/chapter-1-effective-water-simulation-physical-models)。
- 太阳/月亮/星空、有密度纹理和光照层次的移动云群、雨后彩虹、方向光阴影、雨雪粒子、雾和分叉闪电。明亮金色月盘使用 [NASA CGI Moon Kit](https://svs.gsfc.nasa.gov/4720/) 的真实 LRO 月面贴图，球面映射保留月海、环形山和射纹，照明形成连续的盈亏边界；月光和海面高光随月相、月亮高度、云雾变化。月亮在夜间按镜头构图保持稳定背景位置，拖动和漫游时不会因方位变化离开屏幕；月升月落以亮度渐变呈现。这是观赏构图，不是精密天文历法。图像来源和署名保留于 `public/licenses/NASA-Moon-Credits.txt`。
- 日间太阳按右上天空构图，尺寸随视口调整，避开顶部工具栏；升落时穿过真实地平线，下半轮由地平线遮蔽。太阳球面、岛屿方向光和海面高光共享渲染方向，实际模拟高度控制升落、日光强度与暖色，天气统一控制日盘和高光的显隐。没有足够天空时恢复模拟方向，避免俯瞰时将太阳贴在海面上。
- 晚霞由共享的物理太阳高度驱动，天空与海面使用一致的线性色彩、方向与天气衰减。参考 [NOAA 火烧云照片](https://www.noaa.gov/noaa-collections/photo-library/wea00182jpg) 的金红云带与蓝紫阴影，以及 [NOAA 对落日颜色的解释与照片](https://www.nesdis.noaa.gov/about/k-12-education/atmosphere/why-the-sky-blue)；照片仅作构图和配色参考，没有作为场景背景素材。
- 实例化浅海鱼群、预分配远海鲸豚模型、水花和喷水粒子。鱼群沿真实海床检查活动范围，鲸豚错开短时浮出或跃出；近景晴朗浅水可透出鱼群，远海与恶劣天气减少透射。
- Web Audio 合成海浪、风、雨、鸟叫、雷声、鲸鱼喷水、海豚短鸣和水花，以及带混响的轻柔背景音乐。动物事件只触发一次，静音时不创建一次性音源。
- 性能优化保留原有画质和场景逻辑：复用逐帧数据、移除草叶零面积三角形，页面隐藏后停止动画帧，静音淡出后暂停音频处理；退出页面时显式释放场景与后期资源。日落材质避免负基数幂运算造成未定义颜色。
- 诗句采用逐字三维字形、金色正面与有厚度的侧面、三种离场动画，并支持系统“减少动态效果”。天空锚点随镜头更新，避免文字在漫游时移到海岛前；显示诗句时淡出介绍标题，为天空留白。毛笔字体采用 [Ma Shan Zheng](https://github.com/google/fonts/tree/main/ofl/mashanzheng) 的本地字形子集，随部署附带 [SIL OFL 许可证](public/licenses/MaShanZheng-OFL.txt)。

写实程度由实时程序材质与几何实现；没有使用摄影扫描模型或录制音频。建议在支持 WebGL 2 的桌面浏览器中开启硬件加速体验。

时间流速支持0.5×、1×、2×、3×、4×和8×；默认0.5×。四季自动轮换与天气自然变化默认开启。

洞内通道向山体延伸18米并作连续弯折，入口视线被真实侧壁遮住而看不到末壁；内部颜色随深度快速降低，洞口火把与灯具已移除，入口只有微弱自然光，洞内转角有局部暖光且不照到洞口。外部洞口、花丛与山体表面清理范围保持原位置。

所有专属录音（灯塔点击、码头点击、山洞点击和两座亭子）仅唱一遍，结束即恢复普通背景音乐，停留原处不会再次触发。再次达到点击触发次数或离开后重新累计指定次数可再播；单曲模式和16倍速仍保留原普通音乐播放方式。大悲咒结束时其他位置的人工灯光立即恢复。

地标专属歌曲只在指定次数触发：山洞和灯塔超过第12次后不循环点击计数，码头只在第3次触发。普通音乐不隐藏诗；专属歌曲开始播放或播放中缓冲时隐藏诗，尚在加载、暂停、结束或退出后恢复原诗句开关。大悲咒也熄灭洞内转角光。

诗句仅在近圆满月（亮面至少99%）、月盘实际投影在当前画面内且未被山体遮挡时显示，仍服从云雾遮蔽和用户诗句开关。非满月、月盘离开画面或被山石挡住时立即隐藏并暂停诗句进度；重新看见满月后继续当前诗联。播放专属歌曲时继续隐藏诗。月盘投影与地形高度采样复用向量，不对整个海岛逐帧做三角形射线检查。

11首专属录音使用96 kbps双声道MP3压缩，总体积由47.70 MB降至28.95 MB（减少39.3%）。保留整首歌曲、原速和音量；原始文件在 artifacts/audio/exclusive-originals/ 单独保存，不加入部署包。点击次数和专属音乐播放规则保持原样。重新制作使用 scripts/compress-exclusive-audio.py。
