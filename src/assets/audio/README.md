场景曲目使用记谱音高和时值合成，移调并自编稀疏伴奏，不含原演奏录音。连同日落曲，共12首器乐音乐；《茉莉花》《月儿明风儿静》按完整简谱演奏，其他曲目为主题节选。

新增八首的参考来源见 `public/licenses/Scenic-music.txt`。曲目原作归各自作者，本项目独立合成伴奏和音色，不分发参考乐谱或演奏录音。《茉莉花》完整覆盖两页24个谱面小节，第1至13小节按反复记号演奏两遍，展开为37小节；保留后半段八度加倍、第22小节起减速与终止和弦。《月儿明风儿静》完整覆盖三页61小节，含5小节前奏、三段各17小节旋律及5小节尾奏。两首不额外插入段落或停顿，末尾保留7秒合成余音空间，均无人声。后者以独立曲目 `yueer` 加入普通歌单，与灯塔点击触发的同名演唱录音 `lighthouse` 分开。

两首的分段文字简谱、逐小节时值、谱面页链接、曲式说明和反复次数保存在 `scripts/full-scores.json`；运行 `python3 scripts/create-extra-scores.py` 会按曲式展开并生成 `scripts/scenic-scores.json`，其中 `form` 记录段落起止拍，`tempoChanges` 记录速度变化。参考谱的钢琴左手伴奏由本项目独立稀疏伴奏替代。完整曲式与减速分别由 `tests/full-scenic-scores.test.js`、`tests/test_scenic_score_timing.py` 验证；后者使用合成时同一 NumPy 环境运行。

可编辑 `scripts/scenic-scores.json` 的声部音高和拍数，通过 `python3 scripts/render-scenic-music.py` 重新合成；制作需要 NumPy 和 ffmpeg，网页只播放成品。可在命令末尾传入曲目ID，只重生成指定曲目，例如 `python3 scripts/render-scenic-music.py molihua yueer`。八首新增曲目的输入与稀疏伴奏生成脚本为 `scripts/create-extra-scores.py`，运行后更新对应JSON条目。合成脚本输出32kHz、双声道Ogg Vorbis，再执行 `python3 scripts/export-mp3-audio.py molihua yueer` 仅导出这两首MP3供网页使用；省略曲目ID会导出全部Ogg。旧Ogg保留为生成源，部署仅引用MP3。数值和时长报告在 `artifacts/audio/`。

12首音乐共用一个流式播放器，只在开启声音后请求曲目，最多复用两个媒体节点。普通场景稳定4秒后更新后续曲目，当前曲目保持播放到自然结束；日落优先交接需要当前曲目已播放至少20秒，旧曲先用1.5秒淡至零，再用1.5秒淡入新曲，两条音量包络不重叠。下一曲尚未就绪时保留当前曲目，不临时叠加振荡器底乐。页面隐藏、静音和系统音频中断会暂停，恢复时继续原曲进度。

默认背景音乐80%、环境音30%。两个音量滑块仍独立控制；海浪、风铃、鸟声等内部动态与场景切换保持原样。

## 日落音乐

当前使用《渔舟唱晚》的电子琴合成版。用户已选择天气预报旋律并授权直接合成；主旋律参考公开乐谱，音色、伴奏与混响为本项目生成，听感与天气预报原录音有所区别。

已打包文件为 `yuzhou-changwan-weather.ogg`，约73秒、双声道，所有电子琴声部由数学波形合成，无第三方录音或音色采样。生成源码为 `scripts/render-sunset-music.py`，制作时依赖 NumPy 和 ffmpeg，网页运行时无需这些工具。

以后如需换成原录音，可以将提供的录音放在本目录，使用以下任一文件名，并重新运行 `npm run build`：

- `yuzhou-changwan-weather.mp3`
- `yuzhou-changwan-weather.wav`
- `yuzhou-changwan-weather.ogg`

只保留一种格式。Vite 会自动把录音打包为本地资源并生成适合 GitHub Pages 子路径的地址。用户点击开启声音后才加载；仅在傍晚按同一播放器的先淡出再淡入规则切换，离开日落时段后恢复场景音乐。音源缺失或加载失败时保留其他音乐和全部环境音效。

## 专属录音体积优化

11首用户上传的专属录音使用96 kbps、32 kHz、双声道MP3，保持整首内容、原速和原有音量，不剪切、去静音或额外响度归一化。这是有损压缩，原件保存在 `artifacts/audio/exclusive-originals/`，该目录不会打包进入网页。

可用 `python3 scripts/compress-exclusive-audio.py` 重新生成。脚本每次从原件编码，逐首完整解码并比较实际时长，所有文件验证成功才替换网页资产，避免重复压缩和发布残缺录音。报告为 `artifacts/audio/exclusive-compression.json`。普通场景合成音乐未更改，现有按点击播放、一次播放、暂停、倍速、诗句与灯光规则保持原样。
