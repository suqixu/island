# 宣传片脚本

设置标题栏版本号左侧的电影图标打开影片列表，直接替换原设置弹窗的内容。片单在一个框内逐行显示并可内部滚动；共用一个返回按钮，按访问顺序返回，关闭再打开保留上次页面与滚动位置。每部影片前有播放图标，点击该行即开始播放。底部通栏进度条支持点击和拖动；左侧显示播放/暂停与当前/总时间，右侧显示倍速、音量、截图、全屏和退出，拖回开头即可重看，支持悬停说明与无障碍名称；选片默认进入全屏，浏览器不支持时使用网页全屏画面；Esc 先退出原生全屏，再按可退出影片。底栏默认隐藏，鼠标移至底部或触屏轻触底部唤出，触屏操作结束约2.5秒收起；菜单展开或拖动进度期间保持可见。点击画面暂停/继续，并显示相应图标。音量弹层用竖向滑杆调节影片音乐与环境声的整体音量，并支持静音及恢复；退出恢复漫游原音量。截图保存当前场景的PNG画面。支持拖动进度；倍速默认1.0×，点击打开选项菜单，可直接选择0.5、1.0、1.5、2、3、4倍速，镜头和字幕按倍率播放，音乐保持原速。切后台自动暂停，返回后需点击继续。

当前提供《浮屿 · 四时一日》（180秒）、《浮屿 · 夜的回声》（180秒）、《浮屿 · 观云》（60秒）、《浮屿 · 渔舟唱晚》（60秒）、《浮屿 · 听雪》（60秒）和《浮屿 · 彩虹》（60秒）。全部画面在现有小岛中实时渲染，复用现有模型、纹理、曲库与自然声，花瓣和松鼠分别使用新生成的共享花瓣纹理与毛皮纹理，花叶复用已有阔叶纹理。洞前花头为独立错落的三圈圆瓣，单瓣从浓色根部渐变到透亮边缘，短密花粉簇共享颗粒纹理，颜色鲜艳并按花簇错落分布，花蕊独立以白、粉、红、黄为主；昆虫落点随实际花心和倾斜花茎更新。

## 观云

《浮屿 · 观云》使用第二版脚本 `src/assets/data/films/isola-cloud-watching.json`，共60秒、9个镜头，配乐为曲库已有的《彩云追月》。旁白仅以字幕显示，没有人声；以“你喜欢看云吗？”开场，以“看云，也看时光。”收尾，句间保留空白。

| 时间 | 画面 |
| --- | --- |
| 0–6秒 | 明确零云量的晴空，镜头缓缓仰起 |
| 6–12秒 | 稀疏轻云逐渐显露，缓慢横移 |
| 12–19秒 | 固定构图，白云慢行 |
| 19–25秒 | 延续相同构图，加快风与场景运动 |
| 25–32秒 | 高机位观看现有云群的层次，缓缓向前 |
| 32–39秒 | 黑云浓聚，短暂加速后停缓，不加入降水 |
| 39–47秒 | 风势放缓，镜头拉开，展示满天晚霞 |
| 47–54秒 | 暮色转入月夜，薄云与完整月盘同框 |
| 54–60秒 | 固定机位停留，云量降低露出明月，配乐淡出 |

影片启用已有的全部云形模式，按云量显露不同云群；晴空、云量、风速与暗云色独立调度。快云段的场景速度为8倍，慢云段为0.6倍，字幕与《彩云追月》保持影片原有时间与音乐速率。高机位云景复用现有云层；具体云形、经过月前的时机随本轮场景变化，未额外固定随机种子或编排逐朵云的轨迹。

## 渔舟唱晚

《浮屿 · 渔舟唱晚》替代原《日落小叙》，脚本仍维护在 `src/assets/data/films/isola-sunset.json`，共60秒，配乐使用曲库已有的《渔舟唱晚》。五段内容通过四个镜头展开，最后两段共用固定机位，不再切镜。

| 时间 | 画面 |
| --- | --- |
| 0–12秒 | 完整落日与一海碎金，摄影机缓慢下降 |
| 12–26秒 | 两只归鸟向落日飞远，短桅渔舟缓缓航行 |
| 26–42秒 | 鱼群错峰跃出水面，如银光散落，远处渔舟继续航行 |
| 42–50秒 | 固定机位，红云相送，太阳徐徐没入海平线 |
| 50–60秒 | 延续同一构图，日已落、月未起，余晖与海声中停留 |

时间由同一条 `scene.hour` 轨道连续推进，末十秒保持暮光。月亮、星空及其他天象在本片关闭，退出后恢复漫游原状态。`sky.sun.size` 可为影片指定太阳直径（CSS像素），默认0继续使用原来的自动尺寸，窄屏会限制最大盘面尺寸。

生物过程 `wildlife.sunsetBird`、`wildlife.sailboat`、`wildlife.fishWave` 可用 `clips` 安排，当前无需额外参数，分别复用已有双鸟、短桅渔船、银鱼/水花/涟漪。过程按片段进度采样，直接拖入也能看到，不依赖普通漫游的随机等待；海面落点和渔舟整条航道仍检查海床安全。影片内的显隐轨道避免随机生物在安静片尾再次出现；普通漫游的自然等待与资源池保留。

## 听雪

《浮屿 · 听雪》使用第二版脚本 `src/assets/data/films/isola-snow-watching.json`，共60秒、7个镜头，配乐为曲库已有的《孟姜女哭长城》，保持原速，无人声。全片固定冬季，从初雪、积雪过渡到暴风雪与汹涌海面，最后在亭灯下停留。

| 时间 | 画面 |
| --- | --- |
| 0–7秒 | 码头初雪，镜头缓缓仰起，山影衬出零星雪花 |
| 7–15秒 | 林缘缓慢横移，深色树干与飘雪同框 |
| 15–23秒 | 南峰亭侧面推进，亭檐和石阶渐白，风雪渐密 |
| 23–31秒 | 固定全岛远景，暴风雪斜扫山林，整段无字幕 |
| 31–40秒 | 礁岸低机位观看大浪、浪沫与横飞的雪，保持摄影机稳定 |
| 40–49秒 | 回到南峰亭，风势渐弱，暮色连续转为雪夜，亭灯亮起 |
| 49–60秒 | 沿同向构图缓缓后退，54秒起固定机位；末三秒无字幕，音乐最后四秒淡出 |

暴风雪段使用现有 `blizzard` 天气，复用它的强浪、礁岸飞沫和雪幕；风速、阵风、降雪、雾和云量按轨道变化，不混入雨或雷电。礁岸镜头适当降低雾量以保留浪形。积雪在镜头环境关键点间持续增加，雪夜保留积雪。环境声音量在23–40秒抬高，末段收弱；所有调度仅在播放期间生效，退出后恢复漫游设置。

## 彩虹

《浮屿 · 彩虹》使用第二版脚本 `src/assets/data/films/isola-after-storm.json`，共60秒、8个镜头，配乐使用曲库已有的《平沙落雁》，全片原速、无人声。音乐在风暴段收低，让风雨与巨浪突出；转晴后重新清晰，最后四秒淡出。

| 时间 | 画面 |
| --- | --- |
| 0–8秒 | 晴天白云，小岛全景缓缓推进 |
| 8–15秒 | 码头与岸边初雨，雨丝渐密 |
| 15–23秒 | 乌云聚拢，镜头缓缓抬向压低的天空 |
| 23–34秒 | 台风与暴雨包围小岛；28–34秒一只飞鸟逆风横穿，被阵风推偏后修正方向 |
| 34–43秒 | 稳定低机位观看礁岸巨浪与飞沫 |
| 43–50秒 | 风雨减弱，云层散开，阳光重新照亮小岛 |
| 50–56秒 | 回到海岛全景，彩虹从淡到清晰 |
| 56–60秒 | 延续同向远拉，字幕“风雨之后，总会有彩虹。” |

`environment.typhoon` 与 `environment.roughSea` 分别调度台风云雨效果和海浪强度，允许风雨停歇后保留逐渐消退的余浪。`sky.rainbow.strength` 以0–1轨道调度已有天空彩虹，直接拖到片尾也能看到；观影不蓄积或消耗普通漫游的雨后彩虹记忆，退出恢复自然事件。

`wildlife.sunsetBird` 复用已有飞鸟模型，片段可设置 `count`（1或2，默认2）与 `flight`（`sunset` 或 `crosswind`，默认 `sunset`）。逆风路线捕获片段起点的机位，连续振翅、随阵风偏移并倾斜修正，不受落日光照门槛限制；直接拖入和倒拖使用同一条航线。普通漫游仍按原规则显示自然归鸟。

## 添加新片

在 `src/assets/data/films/` 新建 UTF-8 JSON 文件，文件名唯一即可。网页按文件名排序形成播放列表；修改代码无需同步维护另一份片单。开发服务器会更新页面，部署前执行测试、资源检查和重新构建。

制作新片需要编写镜头脚本；网页不提供录制、剪辑、导入、导出或视频编码。脚本只能引用现有曲目和地标，不能运行 JavaScript 或加载任意外部资源。一份无效脚本会被隔离，其他影片与普通漫游仍可使用。

下面是可以直接保存的12秒码头短片：

```json
{
  "format": "isola-film",
  "schemaVersion": 1,
  "title": "海风来信",
  "duration": 12,
  "music": {
    "trackId": "chunjiang",
    "musicVolume": 0.65,
    "ambientVolume": 0.3,
    "fadeIn": 2,
    "fadeOut": 3
  },
  "shots": [{
    "id": "arrive",
    "start": 0,
    "end": 12,
    "landmark": "dock",
    "camera": [
      {"at": 0, "position": [25, 11, 43], "target": [0, 0, 0], "fov": 48},
      {"at": 12, "position": [10, 6, 23], "target": [0, 0, 0], "fov": 42}
    ],
    "environment": [{"at": 0, "hour": 8, "season": 1, "weather": "sunny", "snowCover": 0}]
  }],
  "captions": [{"start": 1, "end": 10, "text": "沿着海风，慢慢靠岸。", "style": "body"}]
}
```

## 字段

所有时间单位均为秒。总片长1–1800秒，单份脚本不超过1 MiB，最多128个镜头、512条字幕；每组关键点最多128个。限制与通用文案在 `src/config/film.json`。

| 字段 | 说明 |
| --- | --- |
| `format`、`schemaVersion` | `format` 固定为 `isola-film`；版本支持 `1` 与 `2` |
| `title`、`duration` | 网页片名与总片长 |
| `shots` | 连续覆盖整片的镜头，相邻 `end` 与 `start` 相等，不留空隙或重叠；`id` 唯一 |
| `camera[].at` | 相对此镜头开始的时间，首个必须为0，后续严格递增 |
| `camera[].position`、`target` | 相对地标的三维偏移 `[x,y,z]`，分别控制机位与观看点；普通地标按世界方向，亭子按建筑朝向，林间主体按可观察方向 |
| `camera[].fov` | 25–90度；两点使用平滑缓动，三个及以上点构成连续弧线，推荐各段等时长 |
| `environment[].at` | 环境关键点相对时间，首个为0；最后一个后保持当前环境 |
| `hour` | 0至小于24，关键点之间沿较短方向插值，支持跨午夜 |
| `season` | 0春、1夏、2秋、3冬，关键点到达时切换 |
| `weather` | `src/config/weather.json` 的 `presets` 中已有天气，关键点到达时切换 |
| `snowCover` | 0–1，关键点间插值；雨雪与生物退场仍沿用原规则 |
| `captions` | 可省略；全片绝对起止时间、纯文本 `text`，样式 `title`、`body` 或 `ending` |
| `music` | 可省略；`trackId` 为 `src/config/music.json` 中已有ID，两个音量0–1，`fadeIn`、`fadeOut` 为整片首尾渐变秒数 |

每段镜头使用短暂淡出/淡入衔接，手机窄画幅适当拉远机位，已有相机安全机制继续生效。地表高度保护不能代替人工检查构图，制作后应真实播放，检查山体、树干或建筑是否遮挡主体。

| 地标 | 观看位置 |
| --- | --- |
| `island`、`dock`、`reef`、`lagoon` | 全岛、码头、礁岸、泻湖 |
| `cave`、`flowers` | 洞口、实际花丛 |
| `woodland` | 白天读取本轮林间生物的实时位置，观察时平滑跟随；主体退场后停留，下一镜头重新选取。夜间取当前林缘萤火虫区域；无活动主体时回到栖息地 |
| `lighthouse` | 灯塔 |
| `pavilion-south`、`pavilion-east` | 南峰亭、东海亭 |
| `moon` | 月夜预设地标；月亮仍遵循现有天象规则 |
| `moths`、`fireflies` | 实际亮灯飞蛾与本夜萤火虫群落 |

## 对普通小岛的影响

播放临时控制视角、时间、季节和天气，并暂停自动轮换与手动拖动。退出恢复观影前的镜头和设置，以及原音乐模式、曲目、播放位置与暂停状态。暂停期间，画面、模型和声音一起暂停；静止画面不持续重绘，拖动、窗口变化与迟到贴图会同步必要的一帧。转屏直接重新适配当前镜头，不改变影片时间或重新选择拍摄主体。

影片进度与模型累计时钟分离：重播重置镜头和字幕，模型时间持续向前，避免退出后云、帆船或亭子等待时钟追平。动物按原有天气和生命周期自然活动，每次重播不保证逐帧相同，也不强制它们在镜头中出现。

声音仍在用户点击播放后按需加载；加载失败时画面可静音播放。普通漫游的默认静音、画质和资源加载策略保持原有配置。

## 第二版：调度场景能力

`schemaVersion: 2` 沿用上述镜头、环境和音乐格式，并增加 `tracks`（参数轨道）与 `clips`（有起止时间的过程）。第一版继续兼容。未知能力、未知参数、超出实际容量、重叠的独占过程都会在载入时报告错误，不会执行任意 JavaScript。

《浮屿 · 夜的回声》为 **180 秒、13 个镜头**。同一路线向前游览；飞蛾与萤火虫分别对准实际灯位与当夜群落；76–84 秒固定机位连续展示月相，84–98 秒展示星座连线和中文名称；天气合为一个镜头，之后是流星、彗星、极光，154 秒开始月食并在血月处结束，不展示复圆。新增字幕随景物分段出现。

每条轨道首个关键点必须在0秒。默认 `step` 保持当前值；数值与向量支持 `linear` 和 `smooth`，也可在关键点指定该点至下一点的插值方式。小时与月相沿较短方向插值；完整月相循环应经过若干中间点，不能只写0和1。镜头环境先应用，再应用参数轨道，最后合成过程参数。

下面字段可加入一份第二版脚本（时间须在其片长内）：

```json
{
  "tracks": [
    {"capability":"sky.constellation.mode","keyframes":[{"at":0,"value":"off"},{"at":20,"value":"labels"},{"at":34,"value":"off"}]},
    {"capability":"scene.motionRate","keyframes":[{"at":0,"value":1},{"at":40,"value":6},{"at":60,"value":1}]},
    {"capability":"sky.moon.framing","keyframes":[{"at":0,"value":"complete"}]},
    {"capability":"lights.path.intensity","keyframes":[{"at":0,"value":1},{"at":40,"value":0}]}
  ],
  "clips": [
    {"id":"meteor-pass","capability":"sky.meteor","start":62,"end":76,"parameters":{"burstCount":18,"maxActive":24,"burstInterval":4,"flightDuration":1.1,"lingerDuration":0.3,"brightness":1.2}},
    {"id":"moon-shadow","capability":"sky.lunarEclipse","start":80,"end":176,"parameters":{"duration":96}}
  ]
}
```

`scene.motionRate` 控制该段场景运动的推进速度，与播放器手动倍率相乘；累计运动时间使用轨道积分，拖动不倒退模型时钟。天象进度仍由片段时间和 `duration` 决定，字幕保持镜头时间，音乐播放速率始终为1。可以让近景舒缓、天气快速流转，不需要整片使用相同速度。

当前能力覆盖昼夜、季节、天气、月相、风雨雪雾及视觉云量；星空、银河、星座、月盘显示/尺寸/完整构图；流星批次数量、并发上限、间隔、寿命、方向和亮度；彗星样式、时长和亮度；极光形态与亮度；日月食进度；灯塔、路灯、亭灯和码头灯；音乐、环境声、画质、诗文，以及各群落的显示和活动数量上限。完整类型、默认值和边界来自 `createCapabilityCatalog()` / 注册表的 `listCapabilities()`，宿主再以模块的实际池容量校验，不在说明中维护第二份范围表。

独立模块可分别调速；共用时钟的 `night`（萤火虫与飞蛾）、`marine`（海鱼与鲸豚）、`lagoon`（泻湖生物）按群落调速。数量是活动/绘制上限，不能绕过天气和栖息地条件，也不会按帧重建资源。灯光强度使用临时环境字段，在各模型内部统一作用于发光材质和真实光源。

`moths` 与 `fireflies` 为观察地标。它们直接读取居民状态和实际灯位，不依赖离屏后可能停止上传的绘制数据。仅在进入或跳转到对应观察镜头时，在当前天气允许的前提下，最多预演30秒现有自然行为，等飞蛾靠近灯边或萤火虫开始闪烁；普通漫游不执行这项预演。动物动作依旧自然随机，不承诺拖动后逐帧一致。

影片结束以暗场收尾；退出、准备取消和报错均恢复原设置、自然天象状态、画质、灯光和音乐，临时参数不写入默认配置。真实渲染验收页为 `tests/scene-capabilities-browser.html`，可检查全片采样、实际流星数量与画面内的星座名称。
