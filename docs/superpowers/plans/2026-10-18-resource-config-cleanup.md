# 资源与配置整理实施计划

> 依据本次用户要求执行；不提交、不推送、不创建 worktree，保留既有工作。

**目标：** 分类现有资源与程序模型，集中维护文案、版本记录、音乐曲库和运行默认值，并更新当前版本说明。

## 目录约定

- `src/assets/textures/{terrain,vegetation,sky,water,structures,boats}/`：运行贴图与原始图片。
- `src/assets/music/`、`src/assets/fonts/`、`src/assets/ui/`、`src/assets/data/`：音乐、字体、界面图片和烘焙数据。
- `src/models/`：现有程序化模型生成模块；没有外部 GLB/OBJ 模型，不制造空模型资源。
- `src/config/`：独立 JSON 配置；运行代码用静态 JSON import，避免增加启动请求。
- `prompts/textures/`：图像生成提示词；`scripts/{music,assets}/`：离线生成脚本；`scripts/music/scores/`：谱面数据。

## 迁移原则

使用现有功能接口，不把着色器公式、几何算法中的数值常量机械转换为配置。配置覆盖用户可调设置、运行预设及既有配置对象的默认值。每次创建模拟状态需独立，不能共享可变 JSON 状态。生成脚本需从自身位置定位项目根目录，构建不依赖 Python 或素材生成工具。
