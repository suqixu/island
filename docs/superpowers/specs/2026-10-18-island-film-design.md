# 浮屿三分钟宣传片与可重播脚本

## 已确认目标

基于现有小岛，通过虚拟摄像机自动游览，配现有背景音乐、环境音效与字幕，形成约180秒的慢游宣传片。脚本直接在项目内维护，网页提供播放列表；以后新增合规脚本即可播放另一部宣传片。用户已确认下列路线及页面内播放器方向。

脚本驱动真实场景，不是编码后的视频文件。镜头、场景设置、字幕与音乐安排按脚本重播；生物继续自然随机活动，因此每次播放的动物动作不要求逐帧相同。

## 分镜

| 时间 | 内容 | 氛围与声音 |
| --- | --- | --- |
| 0–25秒 | 晨光全岛，靠近海岸和码头 | 片名、柔和器乐、海浪 |
| 25–55秒 | 浅海、泻湖与海洋生物 | 海浪与已有生物事件音效 |
| 55–85秒 | 洞前花丛、蝴蝶、蜜蜂与蜻蜓 | 晴朗夏日，近景短暂停留 |
| 85–115秒 | 林间山径、林鸟与松鼠 | 结合本轮真实栖息地取景 |
| 115–145秒 | 春夏秋冬与晴雨雪 | 给天气留出过渡，雨雪时生物退场 |
| 145–165秒 | 灯塔、落日与海面 | 暖色晚霞，音乐平滑延续 |
| 165–180秒 | 亭灯、夏夜萤火虫、月夜 | 返回无雪夏夜，片尾字幕与音乐淡出 |

实际镜头可根据坡面、洞口、亭子与当轮栖息地微调，保持分段时长和主题。不会为了镜头制造生物瞬移或强制在不适宜天气出现。

## 最新确认（覆盖早期导入导出方案）

用户选择“项目维护脚本＋网页播放列表，不做导入导出”；脚本存放 `src/assets/data/films/`，网页自动发现可用影片。宣传片使用现有场景、纹理与声音；随后用户明确要求花朵与松鼠使用Imagegen，已加入共享花瓣与毛皮纹理，该要求覆盖此前“不新增图片”在这两项上的限制；花叶复用已有阔叶纹理，花瓣多彩、花蕊以白粉红黄为主。新增脚本可改变镜头、片长、环境、音乐字幕；通用播放能力不改写小岛的生物与自然规则。

## 使用流程

1. 设置标题栏的电影图标在原设置弹窗内打开片单；只有一个返回按钮，按访问顺序返回并记住上次页面，片单内部滚动。每部影片前有播放图标，点击该行即开始播放。
2. 用户点击播放后，准备必需资源并开启音频。播放前显示片名，随后收起普通漫游界面。
3. 观影浮层仅保留播放/暂停、倍率、退出和可拖动的进度显示。支持拖动进度定位镜头、字幕、环境和音乐；动物继续自然活动。默认1.0×，通过菜单直接选择0.5、1.0、1.5、2、3、4倍速；音乐保持原速。底部为蓝色通栏进度，左侧播放/暂停与时间，右侧倍率、音量、截图、全屏与退出。用户随后补充默认全屏、点击画面暂停/继续并显示图标、底栏只在底部鼠标/触屏交互时唤出，以及截图保存和音量调节；这些要求覆盖此前仅调整布局和倍率菜单的范围限制。未新增画质菜单或全局快捷键。
4. 暂停时镜头、场景动画、字幕和声音同步暂停；继续后衔接当前时刻。切到后台自动暂停，返回后由用户继续。
5. 片尾停留在最后画面，点击播放或拖回开头可以重新观看。退出恢复观影前的镜头、时间与天气季节设置、自动轮换、漫游、画质以及声音设置。
6. 脚本为项目内的UTF-8 JSON文件。新增脚本后自动加入播放列表；无效脚本隔离，不影响其他影片和普通漫游。

## 脚本内容与约束

使用纯数据 JSON，不执行文件内的 JavaScript，不包含本机路径，不内嵌音频或纹理。

- 固定格式标识 `isola-film`，`schemaVersion: 1`，标题、总时长。
- 按时间排序的镜头：起止时刻、镜头路径关键点、观看目标、视野角度、缓动与转场。
- 场景提示：时间、季节、天气、积雪状态，受现有配置允许值约束。
- 字幕：起止时刻、正文和片名/正文/片尾样式。仅显示文本，不解析 HTML。
- 音乐：现有曲目 ID、音量与整片淡入淡出；第一版用一条柔和主曲贯穿，避免频繁换曲。
- 环境音效：沿用现有海浪、风雨、鸟鸣、风铃和海洋生物事件；不新增首屏音频下载。
- 地标引用：全岛、码头、泻湖、洞前花丛、林径、灯塔、两座亭子和月夜；相对地标的镜头在载入后解析为本场景的位置，适应随机栖息地。

校验版本、数据类型、有限数值、有效时段、镜头最小间隔、音量范围、已知地标/天气/音乐 ID。未知格式或不支持的版本拒绝载入。脚本有明确大小与时长上限，避免错误文件拖垮页面。

## 实现职责

- `src/film-script.js`：脚本解析、校验和按播放时间求当前镜头/字幕/场景提示的纯逻辑。
- `src/film-player.js`：播放时钟、播放/暂停/重播/结束/退出状态、场景快照恢复和提示触发；通过窄接口控制场景与音频，不直接接管其他模块内部状态。
- `src/film-camera.js`：地标解析、平滑路径、目标和视野插值、地表与建筑安全检查；复用现有相机安全逻辑。林间观察从实时行为状态读取目标并平滑跟拍，不依赖离屏时未上传的实例矩阵。镜头前后与转场不能穿山、穿亭顶或突然跳转。
- `src/film-ui.js` 与现有样式：播放列表入口、简洁观影浮层和字幕，桌面/触屏均能操作，退出按键可用。
- `src/config/film.json`：按钮和错误文案、默认播放参数；内置示例脚本存放 `src/assets/data/films/`，静态打包。
- `src/main.js`：提供真实地标、环境、相机、声音控制和退出恢复接口；只保留一条渲染循环，播放期间关闭相机自动漫游及用户拖动竞争，继续沿用现有画质与剔除优化。

## 播放与资源处理

影片进度与模型累计时钟分离；模型时钟在重播或退出时不倒退，避免云、帆船和亭子暂停等待追平。退出恢复正常音乐的模式、曲目与播放位置。使用独立的真实秒时间线，暂停不累计时长，不依赖昼夜速度倍率。镜头、字幕、环境和音乐共同读取该时间线。正常掉帧按当前时间定位，不能积压播放过时音效。资源准备和声音启动失败可重试或静音继续，不得让页面卡在黑屏。

音乐通过用户播放手势加载，沿用现有曲库与音频引擎，补齐必要的暂停和淡入淡出控制。音频预加载/准备不改变普通漫游的默认静音与按需加载。结束、退出、重复播放及页面卸载均释放临时事件，不建立第二条 RAF 链。

环境设置按章节安排，晴雨雪通过现有平滑参数过渡。季节或场景跨度过大时采用短暂淡出/淡入，避免雪面突然清空或镜头横穿实体。接近花丛/林径时从实际落点中选择镜头目标，已退场的物种不承诺每次一定入镜。

## 验收

- 单元测试覆盖脚本校验、镜头边界、暂停继续、重播、片尾、后台暂停、状态恢复和提示不重复触发。
- 镜头路径以真实地形/建筑检查，不低于安全高度；触屏宽高比下保持主体可见。
- 真实浏览器完整播放180秒，检查字幕时序、天气季节、夜间画面、声音启停、暂停/继续/退出。
- 加入第二份项目脚本后播放列表可识别并播放；错误脚本不会破坏其他影片或正常漫游。
- 测试现有漫游、音乐、画质、性能剔除与页面释放；运行 `npm test`、`npm run build`、`npm run check:resources`。
- 截图和日志保存到 `tmp/`；用户未授权提交或推送，保留改动供审阅。
