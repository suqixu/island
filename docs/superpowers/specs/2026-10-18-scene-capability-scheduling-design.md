# 小岛场景能力与影片脚本调度设计

状态：用户已确认；已纳入随后要求的星座连线与名称展示。适用于通用运行引擎与影片脚本，不局限于《夜的回声》。

## 目标与范围

脚本可以按时间控制已有的场景功能及其可调参数，包括月相、天象、天气、灯光、声音、生物数量和画质。流星数量、出现间隔等目前没有公开设置接口的已有行为参数，也要通过模块接口开放。新增能力以后只需注册一次，所有影片即可使用。

这里的“任何已有能力”指场景功能与现有参数，不包含打开设置弹窗、截图下载、全屏和管理播放列表等应用操作。不把几何算法内部常量、任意 JavaScript 或任意 Three.js 对象路径作为脚本命令。

本轮交付包括通用调度引擎、已有场景功能的适配器、可查询的能力目录、脚本格式说明，以及接入后的410秒《夜的回声》。旧影片继续播放。普通漫游沿用原来的设置与随机规则。

## 当前接口与方案选择

当前 `film-scene.js` 每帧只应用时间、季节、天气、积雪。流星、彗星和极光通过 `atmosphere.js` 转发到各模型，主要只有模式设置接口。月食与日食已经有可按进度计算状态的纯函数，但普通运行的调度器使用各自累计时钟。流星池当前为32个槽位，画质默认并发上限为9，每批随机1至9颗。

推荐“能力注册表＋属性轨道＋过程片段”。模拟点击设置按钮会改变相机，无法可靠拖动；脚本直接访问内部对象会使模块之间互相依赖，也难以恢复状态。

## 能力注册表

新增独立模块管理能力定义。每项包含稳定名称、中文说明、参数类型、默认值、取值范围、插值方式、读取/应用接口，以及快照恢复接口。提供 `listCapabilities()`，脚本校验与说明读取同一份定义，避免各自维护参数表。

能力定义中的范围来自当前模块的资源容量和实际实现，不写成没有渲染效果的假参数。模块缺少接口时，为拥有该状态的模块增加窄接口；不修改冻结的默认配置，不从播放器直接写网格内部状态。

| 能力组 | 本轮覆盖 |
| --- | --- |
| 时间与环境 | 时间、季节、月相、天气预设、云量模式、积雪，以及覆盖预设的风速、风向、雨雪、雾、云量等现有环境参数 |
| 天空 | 流星、彗星、极光、日食、月食、星座指引；已有星空/银河的显示与强度 |
| 流星参数 | 模式、每批数量、最大同时活动数量、批次间隔、飞行时长、拖尾时长、亮度、方向；沿用现有渲染和轨迹算法 |
| 其他天象参数 | 现有彗星样式与时长，极光形态与强度，日月食的持续时间和进度 |
| 灯光 | 自动/关闭灯塔/关闭全部模式，以及灯塔、路灯和凉亭灯的启用与强度 |
| 生物与船只 | 当前已接入生物/船只群落的启用、数量与已有运行参数；数量受实际池容量约束，生物继续遵循天气和栖息地条件 |
| 声音 | 现有曲目、音乐模式、暂停、音乐音量、环境音量；影片倍速不改变音乐速率 |
| 镜头与呈现 | 现有地标、关键帧运镜和视野角度；画质、现有诗文显示开关；不调度应用面板操作 |

数量参数区分“每批数量”与“同时活动上限”。本轮流星数量允许0至32，默认继续随机1至9并使用原画质上限；影片显式指定数量时，临时使用指定的有效上限。超过池容量的脚本在加载时明确报错，不静默截断。其他生物同样声明实际容量，不按帧重建模型来扩大数量。

新增可调默认值和参数文案放在对应JSON配置。几何、着色器和数值算法内部常量继续留在实现中。

## 脚本格式

保留 `schemaVersion: 1`，新增 `schemaVersion: 2`。第二版沿用镜头、环境、字幕和音乐结构，增加 `tracks` 与 `clips`。解析器先将两版规范化，再交给同一采样器。

属性轨道描述持续状态，过程片段描述有起止时间的事件。示例：

```json
{
  "tracks": [
    {
      "capability": "scene.moonPhase",
      "interpolation": "step",
      "keyframes": [
        { "at": 0, "value": 0.5 },
        { "at": 118, "value": 0 },
        { "at": 122, "value": 0.125 }
      ]
    }
  ],
  "clips": [
    {
      "id": "meteor-pass",
      "capability": "sky.meteor",
      "start": 216,
      "end": 230,
      "parameters": {
        "mode": "instant",
        "burstCount": 18,
        "maxActive": 24,
        "burstInterval": 4,
        "brightness": 1.2
      }
    },
    {
      "id": "complete-lunar-eclipse",
      "capability": "sky.lunarEclipse",
      "start": 270,
      "end": 366,
      "parameters": { "duration": 96 }
    }
  ]
}
```

示例只展示新增调度字段，完整脚本仍需提供片名、片长和镜头等必需数据。

数字支持线性或平滑插值，枚举、布尔值和数量使用阶梯切换；时间和月相按循环方向插值。每条轨道从0秒开始。同一能力属性不允许重复轨道。相同过程能力的片段不能重叠，除非模块明确声明支持并发。

应用优先级为：观影基线设置 → 原镜头环境 → 全片属性轨道 → 当前片段明确提供的参数。未写的参数继承基线；片段使用 `[start,end)`，离开后恢复该时刻轨道或基线值，不遗留临时设置。未知能力、未知参数、类型错误和越界值都在播放前定位到具体轨道或片段报错。

## 时间与播放控制

唯一主循环不变。每帧按影片绝对时间采样属性和活动片段，再调用现有模块。持续参数仅在值变化时提交，不能每帧调用会重置状态的模式切换接口。

日月食直接复用已有进度计算与渲染，进度取 `(影片时间-片段开始)/持续时间`。月食跨四个镜头仍是一次事件，血月保留原有与天空、海面、岛屿的联动。

流星、彗星和极光增加影片采样入口，复用现有几何、材质和轨迹计算。通过片段相对时间重建状态，拖动时不从片头逐帧追赶。流星批次根据片段时间确定出生时刻，数量、飞行和拖尾都能正确回看。

每次进入观影时生成独立运行种子；同一次观影的暂停、拖动和重播复用该种子，使天象轨迹稳定。随机状态不固定写入配置。动物仍采用自然行为，不承诺拖动后逐帧复现动物动作。

需要参照镜头的天象使用片段起点的镜头姿态，之后保持世界方向稳定。拖动直接进入片段中部时，也从该起点姿态确定方向；不因当前相机转向重新生成轨迹。

暂停冻结影片事件；倍速改变影片时间推进，音乐保持原速。拖动立即显示目标月相、天气、灯光、天象及其进度；原先暂停则保持暂停，原先播放则松开继续。参数不能反向调度播放器本身的暂停或进度，避免轨道改变自己的时间来源。

## 普通漫游与恢复

调度器只在观影期间取得能力控制权。进入前，各模块保存其模式、参数和正在进行的自然事件状态；观影时暂停普通事件调度，使用独立的影片事件状态。退出、报错、取消准备和释放都执行一次幂等恢复。

累计模型时间保持单调，恢复普通事件时同步其时间基准，避免事件等待时钟追平或突然跳到结束。继续恢复原镜头、天气、月相、灯光、音乐曲目/进度/暂停状态和画质，设置面板显示同步恢复。任何临时数量和强度都不写回默认配置或持久设置。

天气、昼夜和季节的原有可见条件继续生效。脚本控制启用和参数，不自动改成晴夜、满月或冬季，也不借用会调整相机的UI预览按钮；影片应显式写出匹配条件。

## 夜的回声接入

运行脚本位于 `src/assets/data/films/isola-night-echoes.json`，已将月相、星座和天象说明转换为第二版可执行轨道与片段，直接进入网页播放列表。

按用户后续要求精简为180秒、13个镜头：76–84秒连续快速月相，84–98秒星座连线与中文名称，天气合并为一段；154–180秒展示月食进入血月，结束不展示复圆、不重复全岛远景。近景、天气与星空采用不同场景运动速率，音乐原速；月亮仅在构图完整的镜头显示，月相段保持统一月面尺寸。字幕增加景物说明与意境。

## 验收

- 能力目录覆盖当前场景设置和列出的模块参数；未知字段/范围错误不能被静默忽略。新注册能力无需修改通用脚本解析器即可使用。
- 流星每批分别指定1、9、18、32颗，以及数量0；验证实际发射数量、活动上限、间隔、拖尾、越界报错和退出恢复，不只检查配置值。
- 在月食开始、血月中段、结束前后暂停及前后拖动，验证月面、天空、海面与灯光统一；跨镜头不重启月食。
- 天象直接拖入中段与顺序播放到该时刻保持同一轨迹和进度；拖出片段后没有残留事件。
- 验证旧版影片、后台暂停、重复播放、准备失败、退出恢复、音乐原速、手机布局和资源按需加载。
- 执行受限并发测试、构建和资源检查；真实浏览器验证180秒影片及关键拖动点，星座镜头中连线与名称均可见，退出镜头后恢复关闭；截图和日志留在 `tmp/`。未授权提交或推送。
