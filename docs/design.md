# 浮屿 · 交互海岛

用户目标：用 HTML 和 Three.js 实现尽可能写实的海岛，包含山、沙滩、海鸟、椰树、云、花、码头、海水、太阳，支持昼夜、四季、晴阴雨雾雷雪和背景音乐及音效。

实现：Vite 提供本地开发和静态构建，Three.js 负责全屏 WebGL 场景。地形、植被、天空和声音程序生成；NASA 月面影像与书法字体本地打包，无需运行时远程素材。独立场景模块共享只读环境状态。

- `src/loading-screen-entry.js` 与 `src/loading-screen.js`：轻量入口先启动加载屏，再异步载入主场景。19句原文每轮洗牌完整覆盖，每1.8秒换句，跨轮不连续重复，统一追加“……”。主场景初始化间隙让出绘制时机，首帧成功后淡出；完成、失败和离开页面均停止文案与装饰动画，支持减少动态效果。
- `src/island.js` 与 `src/terrain.js`：自然岸线、多峰山体、椰树及森林、岩石、花朵、码头、海鸟，四季材质和风动画。
- `src/forest-canopy.js`：普通树的分层细枝和独立弯叶片模板，实例化叶簇间保留透光空隙；细枝、树干和冠层共享根部风动，季节、积雪和画质计数同步。
- `src/lighthouse.js` 与 `src/lighthouse-layout.js`：西峰顶旁的旧白墙灯塔、贴合实际三角坡面的石基和入塔石阶；暖金灯室与软边双向扫光随昼夜渐变，旋转采用真实累计时间。
- `src/path-lamps.js`：沿山径外侧交错放置的木铜矮杆暖灯，灯脚采样真实坡面，灯芯随暮色渐亮；复用实例模型和有限点光，避免每盏灯都增加照明开销。
- `src/island-cave.js` 与 `src/cave-vegetation.js`：空心岩洞、多层不规则岩缘和独立三平面颜色/高度/粗糙度纹理；两批次贴岩蕨草及藤蔓覆盖外露岩拱，固定茎柄，叶尖与阴影共用风动，保留季节、积雪和入口净空。
- `src/rest-pavilion.js`、`src/rest-pavilion-layout.js` 与 `src/rest-pavilion-surface.js`：南峰及东峰顶的架空木亭、三面木栏杆、U形三面长凳、飞檐攒尖瓦顶及檐下花格、夜灯和积雪。木柱落在真实坡面，薄木板地面取附近实际地形与石阶上表面的安全高度；只留连接短石阶的一面入口。指定入口不能连接时，创建资源前明确报错。预留屋顶与入亭通道，镜头预设使用实际台面高度，低画质保留造型和灯光。
- `src/ocean.js` 与 `src/atmosphere.js`：多层波浪、浅海颜色、菲涅耳反射、泡沫、天空云层、太阳月亮星空、雨雪雾和闪电。
- `src/audio.js`：用户操作后开启 Web Audio，合成环境音乐、海浪、风、雨、雷、鸟叫，独立音乐和环境音量。
- 每亭四角小铜风铃各有独立摆动相位，可见运动和 `onChime` 撞击事件共享实际摆角，同时限制单铃和整亭连响频率；主循环按对应铃口世界位置计算距离及左右声像。Web Audio 合成五声音高、快慢衰减的金属泛音和轻微余响，独立环境音路由、并发上限与结束释放，静音不建临时音源。
- `src/sailboat-motion.js` 与 `src/sailboats.js`：少量预分配远海双帆小模型，每轮选择完整安全慢航路径，位置按真实累计时间连续推进，淡出后才重选位置和数量；昼夜均可出现，云雾天气影响可见度。
- `src/simulation.js`：可测试的环境时间、季节循环和天气参数。
- `src/wind.js`：按真实时间推进的随机风场，每次场景初始化使用独立种子；天气决定平均风强，平滑阵风、缓慢转向与不同周期的涌浪波群打破重复。`wind`保持0到1，`windSpeed`为场景风速，`windDirection`为单位二维方向，`gust`和`swell`为0到1。
- `src/moon.js` 与 `src/moon-framing.js`：月龄归一化、连续亮面比例和八种月相；模拟日推进月龄。月盘球面受光与海面月光共享同一相位和渲染方向。暗面完全透明，只显示受光的月牙、弦月或凸月；明暗交界在受光侧采用约一像素的软边。月盘位置按镜头构图固定，夜间随模拟高度显隐，属于观看优化，并非精密天文历法。
- `src/sun-framing.js`：在可用天空中安排右上方太阳，随屏幕尺寸限制日盘，模拟高度为零时盘心穿过真实地平线，低于地平线的部分透明消隐；天空不足时恢复模拟方向。日盘、日晕、短光芒、岛屿方向光与海面碎光共享构图方向；实际模拟高度控制昼夜、升落和色温，平滑天气参数统一控制日盘与直接反光的遮蔽。晨昏天空、云层、雾色、日光及海面反射同步偏暖，日间反射补光保留逆光岛屿细节。
- `src/poem-text.js`、`src/poem-motion.js`、`src/poem-visibility.js`、`src/poetry.js`：完整《春江花月夜》、可测试的逐字运动及明月条件。使用本地毛笔字体轮廓和有厚度的立体字形，无标点，署名“唐 张若虚”。竖排上到下、列从右到左，狭窄天空与横屏自动采用两行横排。按镜头海平面地平线限制诗句区域，保留月亮左侧天空；没有足够天空时隐藏，显示时淡出介绍标题。金色文字每联十秒逐字显现、停留、渐隐或飞散；白天、新月、浓云雾雨雪隐藏，系统减少动态效果时仅柔和显隐。预设镜头过渡时暂停字幕，稳定后重新定位，近景深度随观看距离缩短以避开山体。
- `src/main.js`、`index.html`、`src/style.css`：主循环、镜头控制、中文控制界面、移动端适配、截图和全屏。

声音通过用户点击开启以符合浏览器音频策略。没有 WebGL 时显示明确的错误。暂停时间不暂停海浪与生物。默认夏季晴天，昼夜与四季可自动轮换。首次画面采用斜俯视海岛、前景浅海、远方地平线。

明月夜增加受月相和云雾控制的半球补光、柔和反射填充、海面漫反射与远海蓝色层次，并降低画面遮罩、轻微提高曝光。新月与遮月时自然减弱；金色月盘与光路仍是最亮的视觉焦点。晴朗白天增加可见的暖白日盘、柔和日晕与海面碎光，漫射天空光保留岛屿细节，早晚日光偏暖，夜间太阳完全消隐。

晨昏构图以太阳为主，太阳落尽之后月盘随暮色渐入；月盘、月光、海面反光和诗句共享这一过渡。月亮受光侧临近明暗边界轻微提亮，未受光片元仍丢弃，避免黑色轮廓与灰色暗盘。海面只延长最外一圈至远方地平线，相机同步扩大远裁剪距离；近岸几何保持原密度，使半轮太阳自然贴合海平线。

海面长涌浪由几何表达，法线与浪峰在片元中重建；未解析的短波坡度能量由非周期、沿风向的扭曲细纹补足，逐层过滤像素无法显示的纹理。向下的天空反射以水体色近似遮蔽，避免把海面涂成明亮的天空白带。水色先按海深混合，再随平滑云量、雷暴和雾强度降低饱和度；晴天近岸蓝绿、远海深蓝，阴雨灰青/灰蓝，雾天灰淡，冬季保留冷色调。

验证：时间跨午夜、四季边界和暂停独立测试；生产构建；浏览器检查初始场景、六种天气、四季、夜景、音频按钮、截图、移动布局与控制台。

生态扩展：78 组云采用五款本地密度纹理，顶部高光、底部蓝灰阴影和连续轮廓，按风向积分缓慢漂移。`src/after-rain.js` 记录雨天与雷暴湿气，仅转晴且有日光时触发一次彩虹，12 秒渐显、90 秒内消散；夜间和雾雪抑制显示。彩虹在天空着色器中绘制，保留云和地形遮挡。

海洋生物：`src/marine-motion.js` 独立计算真实海床上的安全鱼群栖息地、鲸豚错开运动以及单次事件。每次初始化生成鱼群种子，近岸群中心、鱼群间距、相位和速度随种子变化；同一场景保持栖息地与连续运动，避免逐帧随机跳位。`src/marine.js` 负责实例化三类鱼群、鲸鱼短时浮背和喷水、海豚弧线跃出，以及预分配的短时水花。鲸鱼与海豚只选离岛且远离相机的开阔深水位置，整次活动保持同一锚点；飞鱼已移除。浅海预设靠近岸外鱼群；海面使用按深度、距离、菲涅耳角度及天气衰减的透射，水下不透明模型先写深度，再混合海水，喷雾和水花在海面之后绘制。鸟群增加至 36 只，各自交替拍翼与滑翔，低画质、深夜及雷暴降低可见数量。

动物声音共享画面事件，不依赖独立的随机计时器。`audio.wildlife(event)` 合成呼气、短鸣和落水声，主循环根据相机与事件的相对位置计算距离衰减和左右方位；开启声音后才创建音源，静音、后台与关闭后跳过事件，避免重复或积压播放。

绚烂夕阳：`src/sunset.js` 以物理太阳高度与平滑天气参数提供共享的线性 RGB 配色、晚霞强度、红度和余晖。低空日盘逐渐转朱红并降低辐亮度，避免色调映射把红盘冲白。天空沿日落方位呈现金橙低空云带与玫紫高层，云纹理的亮暗分别接受金红、橘粉与蓝紫色，保留云团细节。海面反射共享同一配色与方向，水体自身继续按水深保持蓝绿。正午和深夜关闭霞光混合，雨雾雪雷抑制暖色；日盘沉落后余晖独立消退。配色参考 NOAA 火烧云与海上落日照片，未引入摄影背景。背景音乐保持原合成音乐，本轮暂不替换。

风中运动：`src/cloud-motion.js` 按真实秒积分云场，速度随共享风速与阵风平滑变化，高层薄云略快，各云固定速度差；保留边缘淡出和跨边界循环。`src/vegetation-motion.js` 提供固定频率的树冠低频摆动、叶尖细颤及平滑风向，将世界位移转回实例局部坐标；根部柔性为零，不逐帧上传实例矩阵。树冠与椰叶的可见材质和阴影深度材质使用相同位移与共享 uniform，季节材质和积雪保持。

整株风动扩展：森林树干、分叉、冠层与椰树干、叶、果通过固定 `aPlantRoot` 和 `aPlantHeight` 共用弯曲场，树干细分后连续弯曲，法线作同场修正；草尖与叶片另叠加细颤。路旁草花补充根尖柔性属性，读取主岛风 uniform，可见与深度材质共用位移；独立道路实例有风状态后备。固定根部和实例矩阵保持，路面、石阶、地形采样及季节覆盖不改变。

常驻泻湖生态：`src/lagoon-life-motion.js` 在真实三角海床上预先验证完整活动范围，三组鱼和海龟游动，内侧湿岸的蟹与浅湖底的龙虾平滑走停。`src/lagoon-life.js` 使用17个实例批次与一个顶点色材质，复用几何；正行列式附肢变换避免左右鳍钳因负缩放翻面，步足按局部海床落脚。精细画质42鱼、3龟、8蟹、5龙虾，流畅画质保留24鱼、2龟、4蟹、3龙虾；不根据昼夜和天气隐藏居民，不增加动物叫声或自发光。主循环使用真实累计时间更新，并接入画质与销毁；泻湖预设靠近水池、允许继续缩放。

随机鲸豚活动：海洋实例初始化生成可复现活动序列，鲸首轮7至8.5秒开始、10.3至11.8秒喷水，后续34至41秒间隔；海豚按12至19秒的独立候选间隔活动，与鲸窗口重叠时顺延至鲸潜下之后。每轮海豚1至4只，低画质上限2只，共用一处远海锚点与固定群成员偏移。候选验证整身、尾、完整游动路径、深水、当前画幅和岛屿遮挡，活动中不重新随机位置；镜头转离则终止该轮，超过一秒的更新时间缺口取消活动并丢弃旧声效阈值，短时低帧率声源使用当帧身体位置。旧纯 helper 的静态默认调用保持兼容。

月相尺寸：`getMoonBackdropSize` 与 `getMoonBackdropScale` 按月相计算尺寸，其他七个预设采用与日盘接近的22至36像素，并补偿背景方向的离轴投影。满月严格沿用原有大月面公式；自动月相在亮面99%至99.95%的窄区间用平滑函数过渡，避免尺寸突然跳变。月盘位置、真实纹理、金色调、透明暗部与夜雾照明保持原逻辑。

月夜海天：`src/sea-horizon.js` 从天空真实水平视线的低空/雾色混合产生共享线性 RGB，主循环每帧一次生成 `env.seaHorizon`，天空与海面读取同一个结果。低空海雾按角高度软衰减，远海按距离渐融至同一颜色，消除原先分别调色与远海雾权重上限造成的色带；近岸160米内保留原渲染。归一化世界方位的连续噪声缓慢改变薄雾宽度、浓淡与微弱云影，绕一周无分区接缝，不改变海平线几何。夜雾与晚霞门控互斥，月相只改变远景亮度，雷暴暗化在共享色中计算一次；白天跳过额外夜雾计算。

随机云量：`src/cloud-cover.js` 以初始化种子生成连续的晴空、少云与多云阶段，使用真实时间平滑过渡，并按阴雨、雷暴、雪和雾设置天气云量下限。主循环仅新增视觉字段 `env.skyCloudCover`，天空云群与海面云层反射共用；原 `env.cloudiness` 继续控制天气、水色及日月照明。云量为零时云群严格隐藏，晚霞只给已有云染色；固定个体阈值决定云团数量与浓淡，不逐帧重新随机或重建材质。

道路与前湾地景：沿原海岸内侧铺设蜿蜒沙土碎石步道，连接码头、三峰回折山径、洞口支线与通往海滩的石阶，共七条路线、约721米；森林和地被保留道路通道，路边以实例化花草和碎石点缀。沿路局部台地最大挖方、填方各2米，影响约1405平方米；沿用原66049顶点的地形网格，地形、道路和植被共用修整后的三角网格高度，避免漂浮或被山坡埋住。岸线、海床、泻湖、洞口物理区域和原峰顶保持原高度。朝向默认视角的山侧洞口切开原地形，并补上厚岩拱、8.5米不规则岩层内壁、起伏泥土地面与大小不一的碎石，壁脚、地面和深处岩壁共用截面边界保持闭合；暖灰石纹采用三份256²颜色、线性高度和粗糙度纹理，世界坐标三平面投影保留中尺度裂隙与颗粒，并以mipmap过滤细纹；洞内逐渐变暗。洞口以五层不规则断面打破平滑圆环，外露岩拱覆盖成片蕨草和长短错开的贴岩藤蔓，茎和叶柄固定，仅叶尖轻摆，可见与阴影共用位移。仅洞体实际范围排除路边花草碎石，洞外走廊保留装饰。小岛前方的泻湖通过局部浅海床与不规则半环沙洲形成，以约10米海口连通外海；继续使用现有海面和水深颜色。既有海床纹理的alpha存储沙洲遮蔽强度，池内几何浪、细波与泡沫同步减弱，外海和海口保留原风浪，不添加水面或纹理采样。保留既有山峰、码头、云量、月相及海洋生物；随机鱼群选址避开新增沙洲并保持整群连续轨迹。

远海鲸豚可见度修正：原鲸长约 11 米、活动距约 500～600 米，宽背出水不足一米且阶段短，手机上容易遗漏。新鲸含尾约 25 米、宽背在水面保持数秒，喷雾随规模增大并延长喷散过程。远海候选同时检查深水、离岛余量、整个身体和游动范围的屏幕边界，以及岛屿对视线的遮挡；没有合适水域时不生成。首次浮背和海豚跃出提前，音效仍按同一次画面事件和真实位置触发。

洞内遮蔽：内壁、洞底和内部碎石采用静态深度遮蔽，入口内侧逐渐变暗、深处更暗，洞外坡口恢复自然光。低画质关闭实时阴影时仍保留洞内深浅；外侧岩拱继续受日月与天气照明。真实手机洞口射线检查确认边缘命中实体岩壁，无天空孔隙。

三峰山径与夜灯：依据实际网格寻找南、西、东三个山头，1.1米宽山径沿坡回折、通过鞍部分叉，接到距真实峰顶不超过2.5米、低差不超过1米的三个落脚点。上山、山脊及洞口外支路全程使用连续水平天然石阶与短转弯平台；真实网格最大纵坡约0.601（约31°），由连续石阶承接。另有约24米的通海滩石阶，从山脚经环岛路连续下降至南侧偏左约0.4米高的干沙处；按累计路程采样石阶，踏面与实际地形逐级衔接。路面采用灰褐土砾、局部岩石与斑驳边缘，坡边挡土石与局部台地连接山体。照片参考 [Zion山路回折](https://npgallery.nps.gov/AssetDetail/3fcc9267f6c344b098346066ce8273af) 和 [West Rim Trail石砌挡土墙](https://npgallery.nps.gov/AssetDetail/5df390ea43b64d729489689c2f3ae3e7)，仅用作走向与结构参考。山洞两侧为两盏石座木火把，暖焰和暖色点光随daylight渐亮或熄灭，暖焰按真实时间轻微摇动；点光采用距离衰减且不新增阴影渲染，在暂停时间和所有画质下正常工作。
# 本轮资源与性能约束

普通森林采用分层树枝与独立弯叶，保留1250株树和九个实例批次；亭子为朱红木柱支撑的中式四角飞檐、三面回纹栏与长凳，每座四角挂四只小风铃。风铃视觉撞击与声音使用同一事件，声音经距离和左右方位衰减。

日落音源为用户授权的天气预报旋律电子琴合成版，73.4秒、双声道32kHz Vorbis。`scripts/render-sunset-music.py` 记录乐句与自编伴奏，说明随 `public/licenses/Sunset-music.txt` 部署。点击开启声音后才创建音频上下文、加载和解码；录音音乐、原合成乐与环境声各有独立总线，夕阳交叉淡入，入夜回到原乐。静音或隐藏保留录音offset，分别在900/100ms淡出后暂停上下文；异步操作串行且检查生命周期和最新播放意图。

渲染修正将晚霞四处 `exp(-pow(signedValue, 2.0))` 改为等价乘法平方，避免GLSL负基数幂的未定义结果。此处是明确数值风险，不能据此断定用户观察到的所有黑闪都源于它。云配置、风积分和字形动画输出复用临时对象，固定颜色与排版信息缓存。草叶仅删除重复尖端和零面积面，所有可见三角形及其position/normal/color/风与积雪属性逐项相同；高画质每帧减少67,200个无效三角形。

`createFrameLoop` 保证仅一条RAF链，隐藏时取消，恢复时继续既有模拟；保持原delta上限和昼夜、风、云、生物时钟。BFCache只暂停而不销毁，真实离开才释放岛屿、洞穴道路、海面、天空、诗字、生物、船、建筑、控制器、后期pass和renderer；共享石阶材质由道路拥有，亭子只借用。常规渲染不保留canvas绘图缓冲，保存照片时即时渲染后调用toBlob。

东亭高平台外侧采用随高差展开的连续粗石斜面，底边按真实三角坡面裁切，邻接台阶之间只保留可见踢面。入口两级浅阶合成一块整宽落脚面，沿用原路的石色、世界UV和季节材质，不重新覆盖原平台；亭位与下方主楼梯保持。独立1255次入口射线检查连续，最大接头步差约9.2厘米，无同高重复面；共享材质仍由道路统一释放。

性能数据来自Node模块更新，排除GPU、启动和诗句切换：七轮各10,000帧，云与字幕中位更新16.36→15.10微秒，采样累计分配318.98→241.44MB。这些数字不等于整体FPS或常驻内存变化。优化前后八场景2,400帧的对象姿态、可见性、几何数量、灯光材质、uniform、雾与字幕一致，证据保存在 `artifacts/performance/`。
